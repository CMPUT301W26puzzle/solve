## Overview
The "Event Participation" app is an Android-based Event Lottery System designed to eliminate the "first-come, first-served" race for high-demand community events. It provides an accessible, fair-chance pooling system where users can register interest over a set period. Once registration closes, an automated lottery samples participants, sending them invitations to finalize their enrollment. It supports three distinct actors: Entrants (participants), Organizers (event hosts), and Admins (system moderators).
## Features
- Lottery-Based Pooling System: Fair sampling of waitlisted entrants, complete with redrawing mechanics if a selected user declines.
- Role-Based Dashboards: Distinct UI flows and permissions for Entrants, Organizers, and Admins.
- QR Code Integration: Automatic generation of promotional event QR codes that entrants can scan to instantly view event details and join waitlists.
- Geolocation Verification: Optional setting for organizers to require and map the location of entrants when they join a waitlist.
- Real-time Notifications: Automated alerts for lottery wins/losses, organizer mass communications, and co-organizer invitations.
- Advanced Event Management: Capacity limits, registration date ranges, manual private invitations, CSV data exports, and co-organizer assignment.
- Interactive Discussion Boards: In-app commenting system for events with role-based moderation capabilities.
- Cloud Backend: Fully integrated with Firebase Firestore (real-time data) and Firebase Storage (posters and QR codes).
